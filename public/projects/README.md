Coloque aqui os prints reais dos projetos, uma pasta por slug:

  public/projects/belo-cao/cover.webp
  public/projects/brasao-burger/cover.webp
  public/projects/ortoclinica-taubate/cover.webp
  public/projects/prospector/cover.webp

Proporção recomendada: 1600 x 1000 (16:10). Depois preencha `cover.src` em
lib/data/projects.ts (ex.: "/projects/belo-cao/cover.webp") e revise o `cover.alt`.
Enquanto `cover.src` estiver vazio, o site usa uma arte tipográfica gerada por CSS.
